# Миграции БД

Чтобы работали **«База тренировок»** (папки, шаблоны) и загрузка тренировки по id, нужно применить миграции.

## Вариант 1: Prisma Migrate (рекомендуется для продакшена)

```bash
npx prisma migrate deploy
```

Либо при первой настройке локально:

```bash
npx prisma migrate dev --name add_workout_folders
```

## Вариант 2: Prisma DB Push (без истории миграций)

```bash
npx prisma db push
```

После применения в БД появятся:

- таблица **WorkoutFolder** (папки базы: Грудь-Руки, Плечи-Спина, Ноги);
- колонка **folder_id** в таблице **WorkoutSession**.

При первом открытии раздела «База» или модалки «Выбрать тренировку» → «Из базы» для пользователя автоматически создаются 3 папки и 9 шаблонных тренировок (seed).
